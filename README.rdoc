== VZS ČČK Třebíč

Member management web application for the Czech Red Cross Water Rescue Service branch in Třebíč (VZS ČČK Třebíč). Manages members, events, trainings, qualifications, life guarding schedules, articles, and photo galleries.

== Tech Stack

* Ruby 1.9.2 / Rails 3.2.11
* Authentication: Authlogic
* Authorization: CanCan
* Frontend: Twitter Bootstrap 2, LESS, CoffeeScript
* File uploads: Paperclip
* Database: SQLite (dev), MySQL (production)

== Running with Podman

Prerequisites: podman, podman-compose

  podman-compose up

The app starts at http://localhost:9000. Default login: admin / admin.

To import a production MySQL dump, place the .sql file in the +dump/+ directory and run:

  podman-compose down -v && podman-compose up

The +-v+ flag resets the database volume so the dump is imported on init. Omit +-v+ on subsequent restarts to preserve data.

To back up the current database:

  podman exec vzs_db_1 mysqldump -uvzs -pvzs vzs_development > dump/backup.sql

== Running without Docker

Requires Ruby 1.9.2-p330 and compatible system libraries (OpenSSL 1.0.x).

  cp config/database.example.yml config/database.yml
  bundle install
  rake db:create db:migrate db:seed
  rails server

== Running Tests

  bundle exec rspec
  bundle exec rspec spec/models/
  bundle exec rspec spec/models/user_spec.rb
